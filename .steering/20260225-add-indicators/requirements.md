# 要求定義: 指標追加（長期金利）

## 概要
日本マクロ経済ダッシュボードに長期金利を追加する。
当初3指標（長期金利・貿易収支・鉱工業生産指数）を予定したが、
データソース調査の結果、実現可能な長期金利のみを追加対象とした。

## 追加指標

### 長期金利（10年国債利回り）
- **指標コード:** `LONG_RATE`
- **単位:** %
- **頻度:** 月次（日次データを月平均に集計）
- **データソース:** 財務省 国債金利情報 CSV
  - URL: `https://www.mof.go.jp/jgbs/reference/interest_rate/data/jgbcm_all.csv`
  - エンコーディング: CP932
  - 日付形式: 元号表記（例: S49.9.24, H12.4.3, R6.1.15）
  - 対象列: 「10年」列
- **用途:** 政策金利との利回り差（タームプレミアム）の分析

## 検討したが不採用となった指標

### 貿易収支
- e-Stat の貿易統計テーブルが年度ごとに分割されており、
  単一 API 呼び出しで全期間取得が困難なため不採用。

### 鉱工業生産指数
- e-Stat での統計表ID が特定できなかったため不採用。

## ユーザーストーリー
- ダッシュボードを見るユーザーとして、長期金利と政策金利を同一期間で視覚的に比較したい

## 受け入れ条件
- [x] `pipeline.py` 実行後、`mart_indicators` に `LONG_RATE` のレコードが存在する
- [x] ダッシュボードの2列グリッドに長期金利チャートが表示される
- [x] 既存の7指標の動作に影響しない

## 付随して修正した不具合
- e-Stat API で差分更新時に「該当データなし（STATUS=1）」が RuntimeError になっていた問題を修正
- `pipeline.py` で `.env` が読み込まれていなかった問題を修正（`load_dotenv()` 追加）
