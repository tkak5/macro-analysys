# ユビキタス言語定義

## ドメイン用語

| 日本語 | 英語（コード上の命名） | 定義 |
|--------|----------------------|------|
| マクロ経済指標 | macro indicator | 経済全体の動向を表す統計指標。本プロジェクトでは7種を対象とする |
| 消費者物価指数 | CPI（Consumer Price Index） | 消費者が購入する財・サービスの価格変動を示す指標 |
| 国内総生産 | GDP（Gross Domestic Product） | 一定期間に国内で生産された付加価値の合計 |
| 完全失業率 | UNEMPLOYMENT | 労働力人口に占める完全失業者の割合 |
| マネーサプライ | M2 | 市中に流通している通貨量（現金＋預金の合計） |
| 政策金利 | POLICY_RATE | 日本銀行が設定する短期金利の誘導目標 |
| 円ドル為替レート | USDJPY | 米ドルに対する円の交換レート（円/ドル） |
| 需給ギャップ | OUTPUT_GAP | 実際の GDP と潜在 GDP の差。プラスで需要超過、マイナスでデフレ圧力を示す |

---

## システム用語

| 日本語 | 英語（コード上の命名） | 定義 |
|--------|----------------------|------|
| コレクター | collector | 外部データソースから生データを取得し raw 層に保存するコンポーネント |
| トランスフォーマー | transformer | raw 層のデータを加工・集計して mart 層に保存するコンポーネント |
| パイプライン | pipeline | コレクターとトランスフォーマーを順次実行するデータ更新処理全体 |
| raw 層 | raw layer | APIから取得した生データをそのまま保存する DuckDB テーブル群 |
| mart 層 | mart layer | ダッシュボード表示用に整形・集計済みのデータを保存する DuckDB テーブル群 |
| 差分更新 | incremental update | 既存データと重複しない新規データのみを追記する更新方式 |
| 指標コード | indicator_code | 各指標を一意に識別するコード（例: `CPI`、`OUTPUT_GAP`） |

---

## データ頻度

| 日本語 | 英語（コード上の命名） | 定義 |
|--------|----------------------|------|
| 月次 | monthly | 1ヶ月単位のデータ |
| 四半期 | quarterly | 3ヶ月単位のデータ（Q1〜Q4） |
| 年次 | annual | 1年単位のデータ |

---

## 変化率

| 日本語 | 英語（コード上の命名） | 定義 |
|--------|----------------------|------|
| 前年同月比 | yoy_change（Year-over-Year） | 1年前の同じ月と比較した変化率（%） |
| 前期比 | mom_change（Month-over-Month） | 直前の期（月または四半期）と比較した変化率（%） |

---

## データソース略称

| 略称 | 正式名称 | 対象指標 |
|------|---------|---------|
| e-Stat | 政府統計の総合窓口（総務省） | CPI・GDP・失業率 |
| BOJ | 日本銀行（Bank of Japan） | M2・政策金利・為替レート |
| CAO | 内閣府（Cabinet Office） | 需給ギャップ |

## 英語・日本語対応表（コード命名用）

| 英語 | 日本語 | 使用箇所の例 |
|------|--------|------------|
| `collector` | コレクター | `estat_collector.py` |
| `transformer` | トランスフォーマー | `base_transformer.py` |
| `fetch` | 取得する | `def fetch(self)` |
| `save_raw` | raw層に保存する | `def save_raw(self, df)` |
| `pipeline` | パイプライン | `pipeline.py` |
| `indicator` | 指標 | `indicator_code`, `mart_indicators` |
| `raw` | 生データ層 | `raw_cpi`, `raw_gdp` |
| `mart` | 加工済みデータ層 | `mart_indicators` |
| `dashboard` | ダッシュボード | `macro_dashboard.py` |
