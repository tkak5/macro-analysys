# プロダクト要求定義書

## プロダクトビジョンと目的

日本のマクロ経済指標を一元的に可視化・分析できるローカルダッシュボードを構築する。
公的機関が公開するデータを自動収集し、指標の動向を把握することで、経済状況の理解と考察を深めることを目的とする。

---

## ターゲットユーザー

- 個人で日本経済の動向を調査・分析したい人
- マクロ経済の学習・研究を行う人

### ユーザーの課題とニーズ

| 課題 | ニーズ |
|------|--------|
| 各省庁・機関のサイトを個別に確認する手間がかかる | 主要指標を1画面で確認したい |
| データがExcelやPDF形式で入手しにくい | グラフで視覚的に把握したい |
| 指標間の関係性が見えにくい | 複数指標を時系列で比較したい |
| 最新データへの更新が手動で煩雑 | ワンコマンドでデータを最新化したい |

---

## 主要な機能一覧

1. **データ収集機能** — 各種API・ファイルダウンロードによる自動データ取得
2. **データ保存機能** — DuckDB による構造化保存（生データ・加工済みデータの2層管理）
3. **ダッシュボード機能** — Streamlit + Plotly によるインタラクティブな可視化
4. **データ更新機能** — パイプラインスクリプトによる差分更新

---

## 成功の定義

- 主要マクロ指標（7種）がダッシュボードで一覧表示できる
- `python pipeline.py` の1コマンドでデータが最新化できる
- 過去データ（可能な限り長期）が時系列グラフで確認できる
- ローカル環境（localhost）でブラウザから閲覧できる

---

## ビジネス要件

- 使用するデータソースはすべて無料・公開データのみ
- APIキーが必要な場合は無料登録の範囲内に留める
- インターネット接続があれば動作すること

---

## ユーザーストーリー

| # | ストーリー |
|---|-----------|
| US-01 | 分析者として、ダッシュボードを開いて消費者物価指数の推移を確認したい |
| US-02 | 分析者として、マネーサプライの変化とインフレ率の関係を比較したい |
| US-03 | 分析者として、需給ギャップの推移を見てデフレ・インフレ圧力を把握したい |
| US-04 | 分析者として、最新データに更新するためにパイプラインを実行したい |
| US-05 | 分析者として、グラフの期間をスライダーで絞り込んで特定期間を詳細に見たい |

---

## 受け入れ条件

- [ ] ダッシュボードが `streamlit run macro_dashboard.py` で起動できる
- [ ] CPI・マネーサプライ・需給ギャップ・GDP・金利・為替・失業率の7指標が表示される
- [ ] 各指標の時系列折れ線グラフが表示される
- [ ] グラフの表示期間を絞り込む操作ができる
- [ ] `python pipeline.py` でデータが更新される
- [ ] データは `data/macro.db` に保存される

---

## 機能要件

### データ収集

| ID | 要件 |
|----|------|
| FR-01 | e-Stat API から CPI・GDP・失業率を取得できること |
| FR-02 | 日本銀行 時系列統計 API からマネーサプライ・政策金利・為替レートを取得できること |
| FR-03 | 内閣府サイトから需給ギャップデータをCSVまたはExcelファイルのダウンロードで取得できること（スクレイピングはサイト構造変更に弱いため原則避ける） |
| FR-04 | 取得した生データを DuckDB の raw 層に保存できること |
| FR-05 | 差分更新（既存データとの重複を除いた追記）に対応すること |

### データ加工

| ID | 要件 |
|----|------|
| FR-06 | raw 層のデータを分析用に整形し mart 層に保存できること |
| FR-07 | 各指標の月次・四半期・年次への集計変換ができること |
| FR-08 | 前年同月比・前期比などの変化率を計算できること |

### ダッシュボード

| ID | 要件 |
|----|------|
| FR-09 | 全7指標が常時表示されること（指標の出し分けは行わない） |
| FR-10 | 時系列折れ線グラフが表示されること |
| FR-11 | 表示期間を指定できること |
| FR-12 | データの最終更新日時が表示されること |

---

## 非機能要件

| 区分 | 要件 |
|------|------|
| 動作環境 | Python 3.13、devcontainer（Docker）上で動作すること |
| パフォーマンス | ダッシュボードの初期表示が5秒以内であること |
| 保守性 | 新しい指標を追加する際にコレクターを1ファイル追加するだけで対応できること |
| セキュリティ | APIキーは環境変数（`.env`）で管理し、リポジトリにコミットしないこと |
| データ保持 | 生データはすべて保持し、再加工できる状態を維持すること |
| オフライン動作 | データ取得済みであれば、インターネット接続なしでダッシュボードを閲覧できること |
